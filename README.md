# JUI for Android

A calm place to write — the Android port of JUI (macOS) and JUI for iPhone.
See `CLAUDE.md` for how it is built and why.

## Install on a phone

`apk/JUI.apk` installs on any Android 10+ phone. Copy it to the phone (or
download it from GitHub), open it, and allow "install unknown apps" for
whichever app opened it. Installing a newer `JUI.apk` over the old one keeps
the notes; uninstalling deletes them.

Rebuild it with `./apk.sh`.
